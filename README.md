# Trilha Java Básico — Conta Bancária

Exercício de introdução à programação Java: um programa de terminal que coleta dados de uma conta e apresenta uma mensagem com as informações fornecidas.

## Projeto

O código-fonte está em [conta-banco/](./conta-banco/).

- **Linguagem:** Java
- **Conceitos:** variáveis, tipos de dados, entrada e saída no terminal
- **Ambiente:** JDK e terminal ou Visual Studio Code

## Executar

~~~bash
cd conta-banco
javac -d out src/ContaTerminal.java
java -cp out ContaTerminal
~~~

Use dados fictícios ao executar o exercício. Este repositório é didático e não implementa operações bancárias reais.
